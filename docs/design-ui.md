# UIライブラリ / スタイリング方針

## ターゲットデバイス

- **iPhone 17（モバイルファースト）** で使用する前提
- 最小サポート幅: **375px**（iPhone SE 以降をカバー）
- デスクトップは崩れない程度でOK。最適化はしない

## スタイリング

**Tailwind CSS + shadcn/ui**

- shadcn/ui はコピー&ペースト型で `components/ui/` にソースが配置される
- AIがコンポーネントの中身を直接読める・編集できる
- Tailwind のユーティリティクラスはAIが最も正確に生成できるスタイリング手法
- デザイントークンは **shadcn/ui のデフォルトに従う**（個別定義しない）

### ステータス色

カロリー収支のステータス表示に使う色だけ定義:

| ステータス | 色 | 用途 |
|---|---|---|
| まだ食べれる | 緑系 | 収支 < -200 kcal |
| いい感じ！ | 青系 | -200 ≤ 収支 ≤ 200 kcal |
| 食べ過ぎ | 赤系 | 収支 > 200 kcal |

## グラフライブラリ

**Recharts**

- React ネイティブ、宣言的APIでAI生成精度が高い
- 学習データが豊富で安定したコード生成が期待できる
- **`'use client'` が必須**。データ取得は親の Server Component で行い、props で渡す

### 用途

| グラフ | 種類 | 画面 |
|---|---|---|
| カロリー収支推移 | 棒グラフ | ダッシュボード |
| 体重推移 | 折れ線グラフ | ダッシュボード / 体重記録 |

## アクセシビリティ

- タップ領域 **44px 以上**（Apple HIG 準拠）
- その他は shadcn/ui のデフォルトに任せる
