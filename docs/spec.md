# CalorieBuddy — MVP 仕様書 v1.0

> AI駆動カロリー収支管理アプリ（自分専用）
>
> 2026年3月1日

---

## 1. プロジェクト概要

### 1.1 コンセプト

AIを活用したカロリー収支管理アプリ。食事内容をテキストで入力するだけでGemini AIがカロリーを推定。体重・運動・歩数から消費カロリーを自動計算し、「食べ過ぎかどうか」をざっくり管理する。AIによる励ましメッセージや豆知識でモチベーション維持もサポート。

### 1.2 ターゲット

自分専用（シングルユーザー）

### 1.3 プラットフォーム

- **Phase 1**: Webアプリ（レスポンシブ対応）
- **Phase 2**: ネイティブアプリ化（Expo）+ HealthKit連携（将来検討）

## 3. MVP機能一覧

### 3.1 ダッシュボード（ホーム）

アプリのメイン画面。今日のカロリー収支を一目で把握できる。

- 今日のカロリー収支サマリー（摂取 - 基礎代謝 - 運動消費 - 歩数消費 = 収支）
- ステータス表示：「食べ過ぎ」「いい感じ！」「まだ食べれる」の3段階
- AI励ましメッセージ（Geminiが今日のデータをもとに褒めたり、ダイエット豆知識を提供）
- 週間・月間推移グラフ（カロリー収支 + 体重）

### 3.2 食事入力

2つの入力モードをトグルで切り替え。

#### AIモード

- テキストエリアに食べたものを自由入力（例：「牛丼、味噌汁、サラダ」）
- Gemini APIが各品目の推定カロリーを返却
- 推定結果を一覧表示 → 確認して保存
- 保存時に食事タイプ（朝食/昼食/夕食/間食）を選択
- ユーザーが推定値を修正可能

#### 手動モード

- 品名 + kcal を直接入力（例：「おにぎり 200kcal」）
- 食事タイプ（朝食/昼食/夕食/間食）を選択
- シンプルなフォームで即保存

### 3.3 運動入力

- 運動種類を選択（ランニング、ウォーキング、筋トレ、水泳、サイクリング等）
- 時間（時間・分）を入力
- METs値 × 体重 × 時間で消費カロリーを自動計算
- 歩数入力欄（Phase 1では手動入力）

### 3.4 体重記録

- 日ごとに体重を手動入力
- 体重推移グラフ表示
- 目標体重との差分表示（任意）

### 3.5 プロフィール / 設定

- 身長・生年月日・性別の登録（基礎代謝計算に使用）
- 目標体重の設定（任意）

## 4. カロリー計算ロジック

### 4.1 基礎代謝（BMR）

ハリス・ベネディクト式（改良版）を使用：

- **男性**: 88.362 + (13.397 × 体重kg) + (4.799 × 身長cm) - (5.677 × 年齢)
- **女性**: 447.593 + (9.247 × 体重kg) + (3.098 × 身長cm) - (4.330 × 年齢)

※年齢は保存せず、`birth_date` から計算時点の日付で算出する。

### 4.2 運動消費カロリー

```
消費カロリー = METs × 体重(kg) × 運動時間(時間)
```

#### METs値一覧（主要な運動）

| 運動種類             | METs値 | 例：70kg・30分 |
| -------------------- | ------ | -------------- |
| ウォーキング（普通） | 3.5    | 約123 kcal     |
| ウォーキング（速歩） | 5.0    | 約175 kcal     |
| ランニング（軽い）   | 7.0    | 約245 kcal     |
| ランニング（速い）   | 11.0   | 約385 kcal     |
| 筋トレ（中程度）     | 5.0    | 約175 kcal     |
| 筋トレ（高強度）     | 8.0    | 約280 kcal     |
| 水泳                 | 8.0    | 約280 kcal     |
| サイクリング         | 7.5    | 約263 kcal     |
| ヨガ                 | 3.0    | 約105 kcal     |

### 4.3 歩数からの消費カロリー

```
消費カロリー = 歩数 × 0.3 × 体重(kg) / 1000
```

例: 10,000歩・70kg の場合 `10,000 × 0.3 × 70 / 1000 = 210 kcal`

※簡易式。歩幅や速度を考慮したより精度の高い計算は将来的に検討。

### 4.4 食事カロリー推定（AI）

Gemini APIに食事内容テキストを送信し、構造化されたカロリー情報を取得する。

- JSON形式でレスポンスを要求（品名、推定カロリー、信頼度）
- 日本の食事に対応したプロンプト設計
- 推定結果はユーザーが修正可能

### 4.5 カロリー収支判定

```
収支 = 摂取カロリー - (基礎代謝 + 運動消費 + 歩数消費)
```

| 収支                   | ステータス   | 表示イメージ       |
| ---------------------- | ------------ | ------------------ |
| 収支 < -200 kcal       | まだ食べれる | カロリーに余裕あり |
| -200 ≤ 収支 ≤ 200 kcal | いい感じ！   | 適切な範囲         |
| 収支 > 200 kcal        | 食べ過ぎ     | 注意が必要         |

## 5. AI励ましメッセージ機能

ダッシュボードに表示されるAIメッセージ。モチベーション維持が目的。

### 5.1 メッセージ種類

- **励まし・褒め**: 「今日はカロリー管理が完璧！この調子！」
- **ダイエット豆知識**: 「タンパク質は満腹感が持続しやすいよ」
- **運動アドバイス**: 「階段を使うだけでも消費カロリーが増えるよ」
- **優しいフォロー**: 「食べ過ぎても大丈夫、明日調整すればOK！」

### 5.2 実装方式

- Gemini APIに今日のカロリー収支データを渡し、状況に応じたメッセージを生成
- ダッシュボード表示時に毎回リクエスト（自分専用でアクセス頻度が低いためキャッシュ不要）
- トーン：フレンドリーでポジティブ、決して責めない
